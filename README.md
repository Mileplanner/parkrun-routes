# **🏃‍♂️ Parkrun Routes (KML)**

A centralized collection of KML (Keyhole Markup Language) files detailing exact routes for parkrun events worldwide, neatly organized by country.

## **📁 Structure**

parkrun-routes/  
├── Australia/  
│   └── Albert Melbourne.kml  
├── United Kingdom/  
│   └── Bushy Park.kml  
└── ...

## **🗺️ How to Use**

* **Google Earth / Google My Maps:** Create a new project or map and select **Import KML file**.  
* **GPS Watches (Garmin, Suunto, Coros):** Convert the .kml file to .gpx using a free tool like [GPS Visualizer](https://www.gpsvisualizer.com/), then import the .gpx file into your watch's companion app (e.g., Garmin Connect).  
* **Strava:** Convert the .kml file to .gpx. On the Strava website, navigate to **Dashboard \> My Routes \> Create New Route** and click the upload button to import the .gpx file.  
* **Mobile Apps:** Download the .kml file to your phone and open it directly in offline map apps like **MAPS.ME**, **Organic Maps**, or **Gaia GPS**.

## **🤝 Contributing**

Routes change and new events are added constantly. To contribute:

1. Fork this repository.  
2. Add or update the .kml file in the appropriate country folder.  
3. Submit a Pull Request with a brief note on the change (e.g., "Updated Bushy Park winter course").
